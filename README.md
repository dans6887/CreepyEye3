Installation / Setup: None

Windows Users
To run Creepy Eye 3 on Windows devices, follow the following step-by-step instructions.
1. Download or clone the GitHub repository to any folder on your PC
2. Unzip the contents if needed
3. Double-click the CreepyEye3.exe executable file.
4. Wait. 


Turn off the Creepy Eye
1. Open Task Manager and click on the Process tab.
2. Scroll down to Background Processes 
3. Locate and Right-click the CreepyEye3.exe process
4. Left-click End Task
